# Library Management System

A Python-based Library Management System built using Tkinter and SQLite to simplify library operations through a graphical user interface.

## Features

- **Book Management:** Add and manage book records.
- **User Management:** Register and manage library users.
- **Book Search:** Search for books easily.
- **Issue Books:** Issue books to registered users.
- **Return Books:** Manage book return operations.
- **Database Management:** Store and manage records using SQLite.
- **GUI:** User-friendly interface developed using Tkinter.

## Technologies Used

- Python
- Tkinter
- SQLite

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/murkukudineshkarthik-arch/library_managment_system.git
```

2. Navigate to the project directory:

```bash
cd library_managment_system
```

3. Run the graphical application:

```bash
python app.py
```
